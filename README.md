## Week 11: Adding an AI Model to PickleBot

For this assignment, I added Ollama to my pickleball tournament assistant to answer questions that were not covered by my Python rules. The assistant correctly answered questions about the tournament start time and the number of players allowed. However, when I asked whether food was provided, the AI incorrectly claimed that there would be a concession stand, even though this information was never provided. I decided to keep important tournament information, such as location, time, players, and courts, in my Python tool so that the assistant provides accurate answers. I also kept refunds, registration, cancellations, and payments handled by predetermined rules because these requests should be directed to a tournament organizer. This approach helps prevent AI hallucinations and makes the assistant more reliable.
